# dqbf_qbflib

DQBF instances from QBFLIB, organized by contributor as upstream
distributes them.

| Dir | Source | What |
|---|---|---|
| `bloem/` | Bloem et al. | safety synthesis, AMBA / genbuf / counter / bs / mv |
| `tentrup/` | Tentrup | bounded synthesis (BoSy) |
| `balabanov/` | Balabanov–Chiang–Jiang | certification benchmarks |
| `scholl/` | Scholl, Wimmer et al. (Freiburg) | partial equivalence checking |

Fetched from https://www.qbflib.org/DOWNLOADS/dqdimacs.zip
(478 instances). Upstream `.git/`, `__MACOSX/` and `.DS_Store` stripped.

Distributed for research use; per-file licensing follows the original
contributors.
