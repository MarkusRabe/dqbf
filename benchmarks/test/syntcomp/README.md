# SYNTCOMP — Reactive Synthesis Competition

LTL/TLSF specifications for reactive synthesis. Kept in the **original
TLSF format**; `tools/ltlsynth2dqbf` (when implemented) translates to
DQDIMACS for the DQBF backends.

The benchmark repo is ~650 MB — **not committed**. Run `./download.sh`
to clone the upstream repo (sparse, TLSF only) into `instances/`.

| Source | URL |
|---|---|
| Benchmarks repo | https://github.com/SYNTCOMP/benchmarks |
| Competition site | https://www.syntcomp.org/ |
| TLSF spec | https://arxiv.org/abs/1604.02284 |
