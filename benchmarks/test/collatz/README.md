# Collatz reachability

The Collatz map is `c(v) = v/2` if `v` is even, `3v+1` if odd. The
conjecture says every positive integer eventually reaches 1.

These instances ask the *bounded, modular* version: working in `bv[N]`
(so `3v+1` may wrap), does every nonzero `x` reach 1 within a step
budget? We make 0 and 1 a sticky sink (`step(v)=1` for `v≤1`) so
"reached 1" is monotone.

## Encodings (`.eqfob` sources committed alongside)

- **`unrolled`** — `∀x. ∃s_0..s_K.` `s_0=x`, `s_{i+1}=step(s_i)`,
  `(x=0) ∨ ⋁_i s_i=1`. K is the *literal* number of steps. This is
  ∀∃-QBF (linear deps).
- **`succinct`** — `∃f: bv[N]×bv[K]→bv[N]. ∀x. ∀t.` `f(x,0)=x`,
  `(t+1≠0 → f(x,t+1)=step(f(x,t)))`, `(t+1=0 → x=0 ∨ f(x,t)=1)`. The
  step counter is K *bits*, so the bound is `2^K−1` steps. This is
  genuine DQBF: the trajectory is an existentially-quantified function.

## What SAT/UNSAT mean

| | SAT | UNSAT |
|---|---|---|
| unrolled | every nonzero N-bit start reaches 1 in ≤K steps (mod 2^N) | some start needs >K steps |
| succinct | every nonzero N-bit start reaches 1 in ≤2^K−1 steps (mod 2^N) | some start needs >2^K−1 steps |

For the integer Collatz conjecture neither answer is informative once
`3v+1` overflows; these are benchmarks, not number-theory evidence. The
unrolled instances at small K are expected UNSAT (e.g. 27 needs 111
steps); the succinct instances with `2^K ≫` the maximum stopping time
of N-bit inputs are expected SAT *if* no modular cycle exists at that
width.
